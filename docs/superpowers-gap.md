# Superpowers gap list (Pinmind 0.7)

Researched 2026-08-19 against obra/superpowers v6.3.0, obra/superpowers-skills,
local Superpowers cache, Contract Autopilot, and Grok `design` / `execute-plan`.

## Keep

- Proportional routes and independent clarity/span/risk axes.
- Frozen contracts, evidence hashes, locks, redaction, authority gates.
- RU/EN coverage and the write-free `route --file -` bootstrap.
- Compose around domain skills; do not replace PDF, security, Figma, or Grok `design`.

## Add (ahead of Superpowers, cheap)

- Superpowers work loop in the controller: design/alternatives before a
  behavior change; a failing public-seam check before production code; root
  cause before a fix; fresh verification before "done".
- Scale ceremony: simple/operational stay inline with no `.pinmind` artifacts.
- Conservative routing: unrecognized, vague, or contradictory text stays
  `uncertain` and read-only instead of dumping to `software-change`.
- Outcome paraphrases without the old fixture keywords.
- Self-repair: after two same-class failures, re-check evidence and search
  the web or primary sources instead of looping.
- User-scope Grok discovery so a new chat can load Pinmind.

## Do not copy

- Visual Companion, mandatory git worktrees, 2–5 minute plan microsteps.
- A second 3k-line skill library or an always-on model-selection runtime.
- Token-usage theater when the host does not expose authoritative counts.
